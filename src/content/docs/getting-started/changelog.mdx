### 🟢 Version 2.4 – October 16, 2023

- Major release focused on supporting large "directory" style sites (e.g. product catalogs, real estate listings, reviews), but also useful for smaller sites.
- **Sub-Templates:**
  - Allows subdividing a main template into sub-templates, each with its own set of editable fields.
  - When creating a cloned page, you select a sub-template, and only the relevant fields are loaded and shown.
  - Greatly improves performance and manageability for sites with many categories and unique fields per category.
- **Layered Navigation (Product Filters):**
  - New system for creating advanced, layered product filters (e.g. color, size, manufacturer) that update each other dynamically.
  - Makes it easy to build faceted search/filtering for large catalogs.
  - Filter values can be used for SEO-friendly listings and product detail tables.
- **New editable type:**
  - `single_check` editable for true/false fields (requires sub-templates addon to be enabled).
- **Performance improvements:**
  - Only the fields relevant to a page's sub-template are loaded, reducing database load and improving speed.
- **Other enhancements and bug fixes.**

**Source:** [Forum Announcement](https://www.couchcms.com/forum/viewtopic.php?f=5&t=13469)

### 🟢 Version 2.3 – January 13, 2022

- Major new feature: **PageBuilder**
    - Lets users build pages visually from reusable blocks (sections like covers, contacts, teams, pricing, etc.).
    - WYSIWYG block-based editing for end-users, similar to site builders like Wix/Squarespace.
    - Built on top of the Mosaic feature, but with a more visual, drag-and-drop experience.
    - Includes a sample site and a detailed tutorial for creating your own blocks and sections.
- PageBuilder is available under the regular Couch license.
- Various improvements and bug fixes.

**Source:** [Forum Announcement](https://www.couchcms.com/forum/viewtopic.php?f=5&t=13148)

### 🟢 Version 2.2 – April 17, 2019

- Promoted from beta to official release.
- Major new feature: **Conditional Fields**
    - Regular `<cms:editable>` and `<cms:input>` fields can now be shown/hidden and validated based on conditions you define.
    - Great for simplifying complex forms and improving user experience.
    - Works in both regular templates and template globals (with some limitations).
- Various improvements and bug fixes.

**Source:** [Forum Announcement](https://www.couchcms.com/forum/viewtopic.php?f=5&t=11512)

### 🟢 Version 2.1 – May 11, 2018

- Promoted from beta to official release.
- **New `<cms:get_field>` tag** (replaces `<cms:get_custom_field>`, now deprecated):
    - Works with almost all custom and system fields.
    - Can be used as a tag-pair for repeatable regions.
- **Template globals** via `<cms:globals>`:
    - Define editable regions global to a template (not tied to cloned pages).
    - Access via new "Manage Globals" button in admin.
    - Fetch values anywhere using `<cms:get_global>` or `<cms:show_globals>`.
- **Repeatable regions**: new `stacked_layout='1'` parameter for vertical layout.
- **Mosaic support** for advanced repeatable content (tile-based editing).
- **Repeatable region content is now searchable**.
- Various bug fixes and improvements.

**Source:** [Forum Announcement](https://www.couchcms.com/forum/viewtopic.php?f=5&t=11105)

### 🟢 Version 2.0 – June 3, 2016

- Major release: complete redesign of the admin panel.
- **Admin panel theming:**
    - Every element of the admin panel can now be customized or replaced using regular Couch tags and snippets.
    - Create your own admin theme by copying and modifying snippets in `couch/theme/sample/` and activating it in `config.php`.
    - CSS and PHP hooks for advanced theming.
- **Template inheritance:**
    - New system for inheriting and extending templates, making complex site structures easier to manage.
- **Custom routes:**
    - Improved support for custom URL routing and dynamic page requests.
- **Group editable improvements:**
    - Group editables can now be defined as tag-pairs, making template code cleaner and more maintainable.
    - New `collapsed` parameter for group editables to control initial state.
- **Admin panel snippets:**
    - All admin screens (lists, forms, etc.) are now rendered using regular Couch snippets, making deep customization possible.
- **Better add-on/module support:**
    - New architecture allows for more powerful and flexible add-ons that can interact with the admin panel.
- **Other enhancements and bug fixes.**

**Source:** [Forum Announcement](https://www.couchcms.com/forum/viewtopic.php?t=10241)

### 🟢 Version 1.1.1 – May 30, 2011

- Added the ability to create drafts of already published pages
    - The end-user can now make changes to live pages without the fear of messing up anything or his incomplete changes being visible to the world
- Added support for dynamic folders
    - The `template` tag now has a new parameter named `dynamic_folders` that can be set to `1` to allow end users the ability to create and manage folders through the admin panel
- Made several changes that will now make migration of a Couch-managed site to a different machine easier (e.g. from local test machine to production server)
    - Items uploaded through the `image`, `thumbnail`, and `file` type of editable regions are no longer stored with the domain names in their paths
    - Added an import utility script - `gen_dump.php`
        - This may be used to create a dump file that will be applied automatically during installation (see documentation for details)
- Enhanced security by now allowing the `index.php` file within the `couch` folder to be renamed
    - This will allow only users knowing the new file name to access the admin panel
- Fixed the error that occurred when the `send_mail` tag was used more than once in a template
- Fixed the bug where the parser was stripping off all backslash characters that had a single quote following them
- Fixed the bug that was causing the captcha in forms to not appear
- Increased the length of the field storing names of templates to allow names up to 256 characters in length
- Removed the `options` directives from `.htaccess` files
    - This was causing errors on GoDaddy servers
- Fixed the bug occurring on some installations of WampServer that truncated the `ckeditor.js` file, causing the editor not to show up
    - Now using PHP to deliver the JavaScript file
- Upgraded CKEditor to version 3.5.4
    - Language files may be downloaded from [CKEditor 3.5.4 Language Files](http://www.couchcms.com/ckeditor_354_lang.zip)
- Added option in `config.php` to set the location of the default folder to store snippets used by the `embed` tag

### 🟢 Version 1.0.1 – January 11, 2011

- Added rebranding feature to CouchCMS
    - Users with a commercial license can replace Couch's name and logos with that of their own business
    - Added lines to `config.example.php` that can be changed by users to utilize their own information
- Added localization to the admin panel
    - Strings used in the admin panel have been moved to a separate file stored in the `lang` folder
        - Added three locales:
            - English (`EN`, default)
            - German (`DE`)
            - French (`FR`)
        - Users can create their own language files
- CKEditor
    - Fixed the bug where CKEditor did not appear on non-English locales
    - Upgraded CKEditor to version 3.5
    - Added CKEditor language files:
        - German (`DE`)
        - French (`FR`)
        - The rest can be downloaded from [**CKEditor Language Files**](http://www.couchcms.com/ckeditor_lang.zip)
    - Added `spellchecker` as a valid toolbar button that can be used with the `custom_toolbar` parameter of `editable` tags of type `richtext`
    - Added the provision of creating toolbar buttons not natively supported by the `richtext` type by prefixing their names with a `#` character
        - This can be used to create, for example, buttons like Scayt, BidiRtl, BidiLtr, etc…:
        ```php
        custom_toolbar='cut,copy,paste,pastetext,-,spellchecker,#Scayt,#BidiRtl'
        ```
        - Note that these names are case-sensitive and should be used exactly as given in the CKEditor documentation
        - These buttons are not supported by Couch and might not work properly
        - They also may require further tweaks to the `couch/includes/ckeditor/config.js` file
- Fixed some warnings that appeared in `PasswordHash.php` on hosts with paranoid-level security
    - This was happening on hosts with functions `getmypid` and `is_readable` disabled
- Added `enforce_max` parameter to `editable` tags of type `thumbnail`
    - This will allow the created thumbnails to be simply scaled instead of always being cropped
- Modified the `start_on` parameter of the `pages` tag to use `>=` instead of `>`
    - This will cause the tag to fetch pages that match the exact time given in `start_on` also
- Added `return_url`, `cancel_url`, and `custom` parameters to the `paypal_button` tag
- Added `cc` and `bcc` parameters to the `send_mail` tag
